## Retired / Absorbed

The following were considered as Creative Skill Packs but are no longer planned. Their intent is now provided through **Hub Knowledge** rather than implemented as deterministic Creative Skills:

- Coaching
- Education
- Brand Voice
- Pinterest
- Instagram

---

Registration note: skills in this inventory are exposed through the SKILL_LIBRARY index (`packages/studio/src/lib/skills/index.js`). A skill marked `✓` has its module, deterministic analyzer, and test suite in place. A `✓` module that is not yet present in the SKILL_LIBRARY index (currently Story Continuity) is still wired into the runtime registry during the Runtime Integration phase, not before it.
