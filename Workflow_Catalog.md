# Workflow Catalog: Batch 1

## muapi-cli

- Intent -> model/skill selection -> single generation -> optional polling -> asset download.
- Intent -> named skill -> multi-step execution -> normalized outputs.
- Brief -> creative agent planner -> human approval interrupt -> specialist execution.
- Generic endpoint -> OpenAPI schema discovery -> input merge -> dry-run or submit -> poll.

## Open-AI-Design-Agent

- Brief -> dependency-aware deliverable DAG -> review/edit/approve -> execute in order -> register assets -> assemble kit.
- Brand kit -> logo/palette/fonts -> hero/reference assets -> social/poster variants -> motion cutdowns.
- Source asset -> natural-language edit -> versioned asset.
- Session -> messages + assets + jobs -> resumable creative workspace.

## Text-To-Video-AI

- Topic -> script -> voiceover -> timed captions -> music -> timed AI/stock B-roll -> final render.
- AI B-roll failure -> Pexels fallback for the affected interval.
- Checkpoint -> resume from last completed stage.
- Scene JSON -> Remotion composition -> final MP4.
